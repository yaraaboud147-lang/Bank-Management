# Bank Management 🏦

This is a small C++ project I made while learning C++ and OOP.

The idea is a simple bank system with different types of accounts, such as savings accounts and checking accounts.

In this project, I practiced:

- Classes and objects
- Inheritance
- Polymorphism
- Virtual functions
- Function overriding
- Pointers
- Dynamic memory
- Vectors
- Constructors and destructors
- Static members

I made this project to practice the things I was learning and to understand OOP better by using it in a real example.

I'm still learning C++, so I will probably improve this project and add more things to it later.

Thank you for checking out my project! ❤️
